## 最新等長觀察：2026-09-01–09-11 對比 2026-08-01–08-11

9/14 讀取的 GSC 完整資料，各 11 天；這是方向性觀察，不是 28 日結案。

| 範圍 | 點擊（前 → 後） | 曝光（前 → 後） | 曝光變化 |
|---|---:|---:|---:|
| 全站 | 60 → 96 | 5,562 → 6,236 | +12.1% |
| 英文區 | 9 → 10 | 1,760 → 379 | −78.5% |
| 四個英文實驗頁合計 | 2 → 1 | 705 → 135 | −80.9% |

全站點擊 +60% 與英文實驗頁的減少同時存在。不能用全站結果宣稱英文優化成功。

英文區平均排名 17.1 → 7.2、CTR 約 0.5% → 2.6%；因為曝光大減，必須再查是否只是低排名查詢消失造成組成改變。四頁合計僅 1–2 次點擊，樣本不足以判斷穩定轉變。

## 歷史技術交付

- 首頁 Mobile LCP：13.10s → 隔離測試 3.16s → 正式上線約 2.72s。
- Lighthouse Mobile Performance：約 73 → 96。
- 全站公開驗收：122/122 sitemap URLs；116/116 桌機／手機三語案例。
- 170 個站內連結與 92 張圖片通過當次檢查。
- 14 條舊網址改成對應內容頁的單次轉址。

這些是各次歷史測試的成果，並非本日重新量測。效能為實驗室數據，不代表所有真實使用者的 Core Web Vitals 都通過。
