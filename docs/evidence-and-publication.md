## 這份 repo 提供什麼

這是一份真實專案的去識別化作品集。案例來自公開網站驗收、實驗紀錄與第一方 Google Search Console；原始營運與回滾資料留在獨立私有 repo，含敏感欄位的原始擷取僅留本機。

| 資料 | 性質 | 能證明什麼 |
|---|---|---|
| data/search-checkpoint-2026-09-14.json | 第一方介面抄錄後去識別化的實測摘要 | 等長期間計數與可重算變化；不是公開 GSC 存取權 |
| data/recrawl-checkpoint-2026-09-16.json | Google 索引介面的實查摘要 | 兩頁最後爬取日期前進，一頁尚未前進 |
| examples/*.example.json | 方法展示範例 | 資料結構；不能當實測成績 |
| assets/performance-summary.svg | 歷史量測的示意圖 | 當次效能測試；不是持續監控 |
| assets/gsc-summary.svg | 8/20 歷史報告示意圖 | 舊版不同長度比較，不是最新結果 |

計算器只重算輸入；CI 只能驗證資料格式、算術與公開內容一致性，不能獨立證明私人 GSC 原始數據真實。

## 發布步驟

1. 私有專案保存來源、日期、改動、匿名驗收與回滾。
2. 更新公開案例及 allowlist 欄位；不複製原始後台或 GSC 截圖。
3. 檢查客戶識別、憑證、內部路徑、連結與資料期間。
4. 跑測試，commit 後推送，確認 CI 與 GitHub 閱讀呈現。
5. 發布是版本化的交付；外部效果仍由後續觀察更新。
